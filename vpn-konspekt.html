VPN, netmask ja muud

Algne tekst on säilitatud muutmata kujul.

VPN ja VPS tähendus:
VPN = Virtual Private Network = Virtuaalne Privaatvõrk. See on krüpteeritud tunnel kahe arvuti vahel läbi avaliku interneti. Välismaailm näeb ainult krüpteeritud andmeid, mitte mida saadad.
VPS = Virtual Private Server = Virtuaalne Privaat Server. See on renditud virtuaalarvuti andmekeskuses (sinu puhul Hetzner Saksamaal). Töötab 24/7, sellel on avalik IP-aadress.

Netmask — mis ja miks:
Netmask ütleb arvutile mis on võrk ja mis on host:
IP:       10.0.0.5
Netmask:  255.255.255.0

255 = see osa on VÕRK (ei muutu)
0   = see osa on HOST (muutub)

Tulemus:
Võrk:  10.0.0.x  ← kõik selles vahemikus on "naabrid"
Host:  10.0.0.5  ← sina oled see
Eesmärk — arvuti teab kellele saata otse ja kellele saata läbi gateway.

Täielik ühenduse teekond sinu puhul:
Sinu seadistus on:
Sinu arvuti (wg0):  10.0.0.5
VPS (wg0):          10.0.0.1
VPS avalik IP:      70.34.210.248
MSSQL andmebaas:    VPS-il (ainult sisevõrgus nähtav)
Samm 1 — WireGuard käivitub:
Sinu Ubuntu arvutis tekib virtuaalne võrgukaart wg0
See saab tunneli-IP: 10.0.0.5
See on PRIVAATNE IP — internetis seda ei eksisteeri
Ainult tunneli sees on see aadress olemas
Samm 2 — Handshake läbi avaliku interneti:
Sinu arvuti avalik IP (näiteks 85.x.x.x)
        ↓
        saadab UDP paketi → 70.34.210.248:51820
        "Tere! Siin on minu avalik krüptovõti"
        ↓
VPS kontrollib: "Kas tunnen seda võtit?" → Jah
        ↓
VPS vastab oma avaliku võtmega tagasi
        ↓
Tunnel on loodud — mõlemad teavad ühist salavõtit
Samm 3 — Laravel/PHP teeb andmebaasi ühenduse:

Välismaailm näeb ainult krüpteeritud UDP pakette — ei tea et sees on andmebaasipäringud. MSSQL port 1433 pole kunagi avalikult internetis avatud — ainult VPN tunneli kaudu ligipääsetav.

Netmask — eesmärk:
Netmaski eesmärk on vastata ühele küsimusele: "Kas see IP-aadress on minu lähivõrgus või mitte?"
Miks see oluline on:
Kui sihtaadress on LÄHIVÕRGUS → saada otse
Kui sihtaadress on VÄLJASPOOL → saada gateway kaudu
Näide sinu seadistusega:
Sinu IP:   10.0.0.5
Netmask:   255.255.255.0  ehk /24

Lähivõrk on: 10.0.0.1 kuni 10.0.0.254

Päring läheb 10.0.0.1 → lähivõrk → saada otse tunneli kaudu
Päring läheb 8.8.8.8  → väljaspool → saada gateway kaudu
Ilma netmaskita arvuti ei teaks kuhu päring saata.

Gateway — mis see on:
Gateway on värav välismaailma. See on seade (tavaliselt router) mis teab kuidas liiklust edasi saata kui sihtkoht pole lähivõrgus.
Igapäeva analoogia:
Sinu kortermaja = lähivõrk
Naabrid majas   = sama võrgu seadmed (saad otse)
Ukse valve      = gateway (läbi tema väljud majast)
Tänav/internet  = avalik võrk
Võrgu analoogia:
Sinu arvuti:  10.0.0.5
Naaber VPS:   10.0.0.1  ← otse, gateway pole vaja
Google:       8.8.8.8   ← gateway kaudu välja internetti

Kõik kolm koos — kuidas töötavad:
Sinu arvuti tahab saata paketi 8.8.8.8 (Google)

1. Arvuti küsib netmaskilt:
   "Kas 8.8.8.8 on minu võrgus 10.0.0.x?"
   Vastus: EI

2. Arvuti saadab paketi gateway'le:
   "Sina tead kuhu see läheb, palun edasta"

3. Gateway (router/VPS) saadab paketi internetti
   edasi õige suunas
Sinu arvuti tahab saata paketi 10.0.0.1 (VPS tunnel)

1. Arvuti küsib netmaskilt:
   "Kas 10.0.0.1 on minu võrgus 10.0.0.x?"
   Vastus: JAH

2. Arvuti saadab otse läbi wg0 tunneli
   Gateway pole vaja

Kokkuvõte kolme reaga:
Netmask — määrab mis on "naaber" ja mis on "kaugel"
Gateway — uks välismaailma, kuhu saadetakse kõik mis pole naaber
Netmask + Gateway koos — arvuti navigeerimissüsteem, ilma nendeta ei tea arvuti kuhu ühtegi paketti saata
